Dashboard analítico premium inspirado no design system oficial da **Porsche Brasil** — `porsche.com/brazil/pt/`. Criado para transformar vendas em decisões estratégicas, com visual minimalista, tema escuro e foco em luxo.

### O que este projeto entrega

**Hero Black Edition 420px** — Cayenne Coupé preta em estúdio, com máscara degradê, glow e assinatura vermelha Porsche.

**3 perguntas de negócio respondidas:**

1. **Principais modelos por cidade** — Barras horizontais + tabela Cidade x Modelo com ticket médio.
2. **Ano/modelo mais vendido** — Donut chart com ciclo de renovação. 2024 lidera com 29%.
3. **Popularidade por cidade** — Cards inteligentes com share, pagamento preferido e insight contextual.

### KPIs

- **TOTAL DE VENDAS:** 100
- **BILHETERIA:** US$ 128,278
- **MODELO TOP:** Cayenne Coupé — 4 unidades (4,0%)
- **CIDADE TOP:** Atlanta — 3 vendas

### Filtros

Modelo (40) • Ano Modelo (2020-2026) • Cidade (79) • Método de Pagamento (9 — Wire Transfer 26%)

Todos reativos. Recalculam KPIs e gráficos instantaneamente.

### Design System

**Paleta:** `#0A0A0A` / `#1A1A1A` / `#1E1E1E` / `#2A2A2A` / `#FFFFFF` / `#D5001C`  
**Tipografia:** Weight 200/300, letter-spacing 0.4em no logo PORSCHE  
**Conceito:** Espaço negativo, bordas 1px, sem sombras claras, linha vermelha de assinatura.

### Stack

HTML5 • CSS3 • Vanilla JS • Chart.js • JSON embutido • 100% client-side • Sem build

### Como publicar

1. Suba o `index.html` para o repositório
2. Settings > Pages > Deploy from a branch > main / root > Save
3. Acesse: `https://seu-usuario.github.io/Porsche-Sales-Dashboard/`

### Base de dados

`base_Porsche_Sanitizada.xlsx` — 100 registros, 12 colunas sanitizadas.
